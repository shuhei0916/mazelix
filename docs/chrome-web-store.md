# Chrome ウェブストア 掲載情報

Chrome ウェブストアのデベロッパー ダッシュボードに入力する内容の下書き。

## ストアの掲載情報

### 名前

mazelix

### 概要（132 文字以内。manifest の description と同じ）

Netflix の字幕を日英で混ぜて表示し、ドラマを観ながら英語に触れる

### 説明

```
Netflix の日本語字幕と英語字幕を、セリフ単位で混ぜて表示する拡張機能です。

画面に出る字幕は、常に日本語か英語のどちらか一方だけ。2 言語を同時に表示しないので、作品への集中を保ったまま、自然に英語のセリフに触れられます。

■ 使い方
1. Netflix で、日本語字幕と英語字幕の両方がある作品を再生します
2. 字幕が自動で日英混ざって表示されます（Netflix の字幕設定は変更不要です）
3. ツールバーの mazelix アイコンから、英語の割合（0〜100%）を変えられます（0% で日本語だけ、100% で英語だけ）

■ 特長
・言語が切り替わるのはセリフの間だけなので、字幕が途中で切れません
・指定した割合どおりに、日本語と英語がまんべんなく混ざります
・英語字幕が聴覚障害者向け字幕（CC）の場合は、効果音の説明を取り除き、大文字だけの文を読みやすく整えます

■ 注意
・日本語と英語の両方の文字字幕がある作品でのみ動作します
・Netflix の仕様変更により、動作しなくなることがあります
・本拡張機能は Netflix とは関係のない個人の開発によるものです

■ プライバシー
個人情報や視聴履歴を収集・送信することはありません。保存するのは英語の割合の設定だけで、お使いのブラウザ内に保存されます。
```

## プライバシーへの取り組み

### 単一用途の説明

```
Netflix の再生画面で、日本語字幕と英語字幕をセリフ単位で混ぜて表示し、作品を観ながら英語を学べるようにします。
```

### 権限が必要な理由

- **storage**
  ```
  ユーザーが設定した「英語の割合」をブラウザ内に保存するために使用します。
  ```
- **ホスト権限（https://www.netflix.com/*）**
  ```
  Netflix の再生画面で、作品の日本語字幕と英語字幕を読み込み、混ぜた字幕を動画の上に表示するために使用します。それ以外のサイトでは動作しません。
  ```

### リモートコードの使用

いいえ（すべてのコードは拡張機能のパッケージに含まれている）

### データの使用

- 収集するユーザーデータ: なし（どの項目にもチェックしない）
- 開示事項の 3 項目（第三者への販売・譲渡をしない、単一用途と無関係な目的で使用しない、信用度の判断や融資の目的で使用しない）にはすべて同意する
